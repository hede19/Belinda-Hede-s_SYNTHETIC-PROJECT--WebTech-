# Belinda-Hede-s_SYNTHETIC-PROJECT--WebTech-
This repository contains the synthetic project code for my WebTech course; it covers lessons 1-7, as those are the lessons I have completed so far.

Campus Connect — Student Hub(this is the name of what I built)

Campus Connect is an interactive student website designed to help students manage assignments, explore campus events, access study resources, and submit feedback.

The project uses HTML5 to structure the website, CSS3 to style it, and JavaScript to provide interactive features. Browser Local Storage is used to save assignments and feedback locally.

The project demonstrates web development concepts learned in Lessons 1–7, including HTML, forms, JavaScript, CSS styling, and responsive web design.

The website runs locally using XAMPP and does not require PHP or a database for its current functionality.
